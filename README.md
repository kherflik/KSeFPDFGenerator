# KSeFPDFGenerator

Generator PDF faktur KSeF na podstawie plików XML KSeF.

Projekt wykorzystuje generator PDF firmy [CIRFMF](https://github.com/CIRFMF/ksef-pdf-generator)
oraz bibliotekę [ksef-client-csharp](https://github.com/CIRFMF/ksef-client-csharp).

Aplikacja jest dostarczana jako samodzielny plik `.exe` dla Windows x64.

## 🚀 Pobieranie

Gotowe wersje można pobrać z zakładki **Releases**:

- `KSeFPDFGenerator-<SHA>-win-x64.zip` – wersja standardowa
- `KSeFPDFGenerator-<SHA>-portable-win-x64.zip` – wersja portable

### Wersja standardowa
